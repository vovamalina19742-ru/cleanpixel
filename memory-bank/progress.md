# CleanPixel: Progress Tracker

## Выполненные задачи (Done)
- [x] **Предотвращение перезаписи:** При отсутствии `--in-place` файл всегда пишется рядом как `<stem>.cleaned.<ext>`.
- [x] **Пакетная безопасность:** Каталоги требуют явного `--output-dir` или `--in-place`, исключая случайную модификацию оригиналов.
- [x] **Атомарная запись:** Уникальные имена временных файлов (`AtomicU64` + PID + timestamp) и fallback-замена для Windows.
- [x] **Progressive JPEG:** Цикл чтения энтропии проходит через все промежуточные маркеры и несколько сканов SOS до реального `0xFF 0xD9` (EOI).
- [x] **Сохранение цветов:** Избирательное сохранение `APP2` (`ICC_PROFILE\0`), `APP14` (`Adobe\0`), `APP0` (JFIF) и PNG `iCCP`.
- [x] **Валидация PNG:** Контрольные суммы CRC-32 для каждого чанка, строгая проверка последовательности `IHDR` ... `IEND`.
- [x] **Инспектор метаданных:** Отказ от regex, переход на парсинг IFD структуры TIFF (Little/Big Endian) и XMP XML.
- [x] **Оптимизация:** Чтение первых 16 байт (`detect_format_from_file`) при фильтрации файлов в директориях.
- [x] **Коды завершения:** CLI возвращает код 1 при ошибке любого файла в пакетном режиме.
- [x] **Тесты:** Интеграционные тесты покрывают 100% добавленной функциональности.
