# CleanPixel: Project Brief

## Назначение проекта
Сверхбыстрая утилита на чистом Rust для криминалистической очистки метаданных (EXIF, GPS, трекинговые GUID, XMP, IPTC, текстовые комментарии) из изображений JPEG и PNG без повторного сжатия (lossless) и без искажения цветов.

## Ключевые возможности
1. **Lossless Stripping:** Удаление метаданных напрямую из байтового потока без декодирования растра пикселей.
2. **Progressive JPEG:** Поддержка многопроходных прогрессивных JPEG с промежуточными таблицами Хаффмана (`DHT`) и маркерами перезапуска (`RST`).
3. **Сохранение цветопередачи:** Сохранение профилей цветов ICC (`APP2`) и цветовых матриц Adobe (`APP14`, критично для CMYK/YCCK). В PNG — сохранение `iCCP`.
4. **Валидация PNG:** Строгая проверка контрольных сумм CRC-32 каждого чанка и структуры `IHDR`/`IEND`.
5. **Инспектор метаданных:** Структурированный разбор TIFF/EXIF тегов (`0x8825` GPS, `0x8769` SubIFD, `0xA420` GUID) и XMP XML.
6. **Защита оригиналов:** Режим по умолчанию никогда не перезаписывает исходный файл, сохраняя копию `<stem>.cleaned.<ext>`.
