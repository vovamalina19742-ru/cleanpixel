# CleanPixel: Architectural Decisions

## ADR-CP-001: Сохранение критических APP сегментов (Color Fidelity)
- **Контекст:** Слепое удаление всех сегментов `APP1..APP15` ломало цветопередачу изображений (обесцвечивание из-за потери ICC профиля и инверсия цветов CMYK/YCCK из-за потери маркера Adobe APP14).
- **Решение:** Проверять содержимое сегментов: сохранять `APP2` при `starts_with(b"ICC_PROFILE\0")` и `APP14` при `starts_with(b"Adobe\0")`. Удалять только метаданные `APP1` (EXIF/XMP), вендорные `APP3..APP13, APP15` и `COM`.

## ADR-CP-002: Поддержка Progressive JPEG через цикл маркеров
- **Контекст:** Предыдущий парсер завершал работу на первом маркере `0xDA` (SOS), обрезая последующие сканы энтропии прогрессивных JPEG.
- **Решение:** Внутри скана считывать байты до реального маркера (учитывая `0xFF 0x00` и `0xFF 0xDm`), после чего возвращать управление во внешний цикл для обработки следующих `DHT`, `DQT` и `SOS` до достижения `0xFF 0xD9` (`EOI`).

## ADR-CP-003: Встроенная CRC-32 таблица без внешних зависимостей
- **Контекст:** Необходимость проверки целостности чанков PNG без раздувания зависимостей крейта.
- **Решение:** Использование `const fn make_crc_table() -> [u32; 256]` для расчета таблицы CRC-32 на этапе компиляции, обеспечивая нулевые накладные расходы и отсутствие внешних зависимостей.
